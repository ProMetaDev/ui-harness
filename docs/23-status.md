## 分项完成度

评分标准是**"一个陌生人能不能在这个领域直接用/信"**，不是"代码写了多少"。

| 领域 | 定义"完成" | 现状 | 完成度 |
|---|---|---|---|
| **内核与契约** | 崩溃不丢、并发安全、可重放 | 全部有测试；缺长时浸泡 | **95%** |
| **审计与可复现** | 哈希链可独立校验 + 攻击可演示 | 独立 Python 校验器 + 7 场景验证包 | **90%** |
| **会话** | 多会话、切换、历史隔离 | CLI + Web 都能切；缺删除/搜索/分页 | **85%** |
| **权限边界** | 策略 + 真实路径 + 边界如实标注 | 有策略/realpath/信任边界声明；**无 OS 沙箱、无观测式效果** | **80%** |
| **工具面** | 真实仓库不卡 | 13 个 + MCP；Windows 无 grep 时退化；无 LSP | **70%** |
| **多智能体** | 拆解 → 隔离 → 验收 → 不自动落地 | 四步都通，真模型跑过 4 次；缺 DAG/仲裁 | **70%** |
| **多 provider** | 可切换、可列、可报错 | 注册表 + 每轮切换；无 OAuth/凭据隔离/价格表 | **65%** |
| **前端** | 四个视图 + 会话 + 实验室 + 鉴权 | 都有；无移动端、无 i18n、默认真模型要手配 | **60%** |
| **文档** | 使用者能照着用 | 23 篇全是设计/复盘；**缺用户向 README** | **50%** |
| **工程化/分发** | CI + 版本 + 安装包 | **CI 无、VERSION 无、tag 无、发布脚本无** | **15%** |

**综合：作为"自己日常用的原型" ≈ 78%；作为"能交给别人用的产品" ≈ 45%。**

差距几乎全在最后两行：**工程化与用户文档**。
