## 分项完成度

标准是**"一个陌生人能不能直接用/信"**，不是代码量。

| 领域 | 现状 | 完成度 |
|---|---|---|
| **内核与契约** | 崩溃不丢、并发安全、可重放；**多写者竞态已修**（CI 抓到的真 bug） | **95%** |
| **审计与可复现** | 哈希链 + 独立 Python 校验器 + 7 场景攻击包 + 实验包对账 | **92%** |
| **会话** | CLI/Web 多会话、历史隔离；缺删除/搜索/分页 | **85%** |
| **权限边界** | 策略 + realpath + 观测式效果 + **Linux Landlock 写沙箱**（fail closed）；Windows 无对等机制 | **90%** |
| **多 provider** | 中继/DeepSeek 都能用；**前沿模型已能真正调工具** + 失败重试 | **78%** |
| **工具面** | 13 个；Windows 无 grep 时退化；无 LSP | **70%** |
| **多智能体** | 拆解→隔离→验收→不自动落地；缺 DAG/仲裁 | **70%** |
| **工程化/分发** | CI 双 job、发布包 + sha256 自校验、bootstrap/preflight/密钥扫描 | **70%** |
| **文档** | README（86 行，使用者向）+ 25 篇设计文档 | **65%** |
| **前端** | 四视图 + 会话 + 实验室 + 鉴权；无移动端/i18n | **60%** |

**综合：自用原型 ≈ 82%；可交付 ≈ 62%。**

## 仍未解决的

| 缺口 | 严重度 | 说明 |
|---|---|---|
| Windows 无沙箱 | 中 | Linux 有 Landlock；Windows 仍是"可执行程序"级信任 |
| 沙箱只限写入 | 中 | 读仍系统级放开；网络默认不限（`UI_SANDBOX_NET=1` 可禁 TCP） |
| 中继抖动 | 中 | 6 次调用里 3 次 `fetch failed`（已加 3 次重试，仍会失败） |
| 无长时浸泡 | 中 | 没有跑过小时级/天级任务 |
| 会话缺删除/搜索/分页 | 中 | 会话多了不好用 |
| 记忆未做 | 中 | 跨会话约束靠提示词 |
| 无 LSP | 低（有意） | 与可审计冲突小，但成本高 |
| 无 changelog | 低 | 版本演进不可读 |

## 一句诚实的话

**133 个测试、38 项门禁、CI 双绿**——这些是自动化能保证的部分。
但最关键的两条（无 OS 沙箱、无观测式效果）**测试再多也补不上**，它们是设计层面的缺口，需要专门的工程投入。
