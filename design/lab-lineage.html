Both columns meet at the run node. producedBy.seq and readBy.seq are real journal events, but the bundle never records which read fed which write. An input → artifact edge would be an inference from order or filenames, so it is not drawn.

Claims are matched by value, not name

claims.json stores only {name, value}. The verifier scans numeric leaves and ignores the claim name, so the card shows the leaf that actually hit. No hit means no line — never a guessed one. f1 searches the same leaves and stays unconnected.
