# greet.js 可用性改进

## 1. 模块被导入时就往 stdout 打印内容

- 触发条件：任何文件执行 `import { greet } from "./greet.js"`，且一次都不调用 greet。
- 实际输出：进程 stdout 立刻多出两行 `hi loom` 和 `hi there`（来自文件末尾第 5、6 行的顶层 `console.log`）。
- 期望输出：导入时 stdout 无任何内容；示例调用移出模块顶层，放到单独的示例文件（如 `example.js`），或仅在直接执行本文件时才运行。
- 影响：把 greet 当库使用的调用方无法分辨哪行输出来自自己，日志与管道输出被污染。

## 2. 纯空白名字被当成合法名字，产出双空格问候

- 触发条件：`greet("   ")` 或 `greet("\t")`。
- 实际输出：`"hi    "`（`hi ` 后接原样的空白），既不是带名字的问候，也不是兜底问候。
- 期望输出：先对 name 做 `trim()` 再判断真值，空白输入走兜底分支，返回 `"hi there"`。

总评：改完再合。
